# NO LONGER BUDGET

A desktop budgeting app for film/TV production, built as a lightweight clone of Movie Magic Budgeting.

## Downloading the beta (Mac)

1. Go to the [Releases page](https://github.com/NikitaBelomestnykh/nlb-budget/releases) and download the latest `.dmg` file under **Assets** (currently `v1.3.1` or newer — older releases before v1.3.1 have a broken install flow, please don't use those).
2. Open the downloaded `.dmg` and drag **NO LONGER BUDGET** into your **Applications** folder.
3. Double-click the app to open it.

## "NO LONGER BUDGET can't be opened because Apple cannot check it for malicious software" — this is expected, nothing is actually wrong

This app isn't yet signed with a paid Apple Developer certificate (that costs $99/year and we haven't set it up yet for this beta), so macOS shows a warning by default for any app downloaded outside the App Store. **Nothing is wrong with the app and it won't harm your computer** — this is just Apple's standard caution for independently-distributed software.

To open it anyway (you only need to do this once):

1. Double-click the app. You'll see a popup saying it can't be opened — click **Done** (or **Cancel**).
2. Open **System Settings → Privacy & Security**.
3. Scroll to the bottom, to the **Security** section. You'll see a message that NO LONGER BUDGET was blocked, with an **Open Anyway** button. Click it, then confirm with your Mac password or Touch ID.
4. Double-click the app one more time. A final dialog will ask if you're sure — click **Open**.
5. From then on, it opens normally, just like any other app — no more warnings.

If you don't see an **Open Anyway** button in Privacy & Security, you likely downloaded an older, unsigned release — please re-download the latest version from the [Releases page](https://github.com/NikitaBelomestnykh/nlb-budget/releases) instead.

## Updates

The app checks for new versions automatically in the background, and you can also check manually any time via the menu bar: **App menu (top-left) → Check for Updates…** (macOS).
