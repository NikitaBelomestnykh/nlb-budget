# NO LONGER BUDGET

A desktop budgeting app for film/TV production, built as a lightweight clone of Movie Magic Budgeting.

## Downloading the beta (Mac)

1. Go to the [Releases page](https://github.com/NikitaBelomestnykh/nlb-budget/releases) and download the latest `.dmg` file under **Assets**.
2. Open the downloaded `.dmg` and drag **NO LONGER BUDGET** into your **Applications** folder.
3. Double-click the app to open it.

## "NO LONGER BUDGET is damaged and can't be opened" — this is expected, nothing is actually wrong

This app isn't yet signed with an Apple Developer certificate (that costs $99/year and we haven't set it up yet for this beta), so macOS shows a scary-sounding warning by default. **The app is not actually damaged and nothing will harm your computer** — this is just Apple's default behavior for any app downloaded outside the App Store that isn't signed yet.

To open it anyway (you only need to do this once):

1. When you see the "is damaged" popup, click **Cancel** (not "Move to Trash").
2. Open **System Settings → Privacy & Security**.
3. Scroll to the bottom, to the **Security** section. You'll see a message that NO LONGER BUDGET was blocked, with an **Open Anyway** button. Click it, then confirm with your Mac password or Touch ID.
4. Double-click the app one more time. A final dialog will ask if you're sure — click **Open**.
5. From then on, it opens normally, just like any other app — no more warnings.

## Updates

The app checks for new versions automatically in the background, and you can also check manually any time via the menu bar: **App menu (top-left) → Check for Updates…** (macOS).
